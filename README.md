## 🛍️ E-Commerce Web App (Frontend)
A fully responsive e-commerce website frontend built using HTML and CSS. It showcases product listings, user interface components like navbar, header, footer, and several product display sections. The site is styled to be responsive across desktop, tablet, and mobile screen sizes.

## 🧰 Tech Stack
|      Tech	                 |    Description                  |
|----------------------------|---------------------------------|
|  HTML5	                   |  Markup language for structure  |
|  CSS3	                     |  Styling, layout, media queries |
|  Flexbox / Grid            |	Responsive layout system       |
|  Media Queries             |	For responsiveness             |
|  Positioning & Z-Index	   |  Sticky navbars, overlays       |
|  Box Shadows, Hover Effects|	Enhanced UI effects            |

## 📱 Responsiveness
This project supports the following screen sizes:

|  Screen Type	  |     Width        |
|-----------------|------------------|
|  📱 Mobile	    |  320px – 767px   |  
|  📱 Tablet	    |  768px – 1024px  |  
|  💻 Desktop	    |  1025px and above|  

Implemented using media queries for optimized display.
